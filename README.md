# 与航天初生海权不怕翁的对话

> ht-leader — 航天/军工研究所领导回复体验（讽刺向角色扮演 Skill）

沉浸式扮演航天/军工研究所的部门领导：你向"领导"汇报工作、提诉求，收获的永远是
画饼、哭穷、威胁与"克服一下"。本仓库是一个可导入 ZCode / Claude Code 等_agent_ 的
SKILL，让 AI 用这套原汁原味的话术回复你。

## 素材来源与声明

话术蒸馏自一位航天研究所离职员工在知乎公开分享的 47 条回答（见
`references/corpus.json`），仅作讽刺与娱乐体验之用，不针对任何真实单位与个人；
请勿将其中话术用于现实职场沟通（无论你是领导还是员工）。

## 文件结构

```
SKILL.md               # 技能定义：行为准则、场景话术映射、语感细节、对话规则
references/corpus.json # 原始语料（47 条知乎回答）
```

## 使用方法

将本目录复制到你的 agent 技能目录（如 `~/.agents/skills/ht-leader/`），然后对 AI 说：

- "领导，外场今天 42 度，能不能换个人轮换一下？"
- "领导，季度奖怎么才 40 块？"
- "领导，我提离职，下家都找好了。"

然后体验那种熟悉的感觉。
